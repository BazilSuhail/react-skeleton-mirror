## Dynamic Class Names

The analyzer handles various patterns:

```tsx
// Ternary
className={isActive ? 'bg-blue-500 text-white' : 'bg-gray-200'}
// → Extracts "bg-blue-500 text-white" (longer)

// Logical
className={isActive && 'active'}
// → Extracts "active"

// Template literal
className={`base ${dynamic}`}
// → Extracts "base"

// Call expression
className={cn('foo', 'bar')}
// → Extracts "foo bar"

// Binary
className={'foo ' + bar}
// → Extracts "foo"
```
